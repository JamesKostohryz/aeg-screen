# aeg-screen

Published output only. This repository holds nothing but the rendered daily AEG
consensus-growth screen (`index.html`) — no source code, no company data, no valuation
algorithms. Those live in private repositories (`aeg-project`, `aeg-valuation`) and stay
private; this repo exists solely so the rendered page can be served as a public web page via
GitHub Pages.

Updated automatically once a day by `aeg-project`'s `screen.yml` workflow, right after the
screen itself runs. Not hand-edited.

NOT A VALUATION. See the page itself for what it is and is not.
